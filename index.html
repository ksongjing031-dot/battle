Minecraft Java 1.20.1 / Forge バトルロイヤル

バトロワ

銃と防具と、ちょっとおかしなアイテムで最後の1人を決める。縮んでいく四角いアンチの中で、チェストを漁り、役職のスキルとオリジナルアイテムを使いこなして生き残ろう。

10人最大参加人数
4ラウンド合計15分（ROUND 1 は縮まない）
10種役職（ランダム）
60種+オリジナルアイテム
導入手順を見る 先にキー設定を確認

01 · 概要

試合の流れ

マップ全体（約300×300ブロック）が戦場です。アンチ（安全地帯）は正方形で、ROUND 1 は縮まず、ROUND 2 からラウンド中ずっと少しずつ縮みます。外にいると2秒ごとに5ダメージ。死んだらスカブとして戦場に戻れ、生存者を倒せば復活できます。最後まで生き残った1人が勝ちです。

START

スポーン

最大体力80・全回復。役職がランダムに決まる。5秒間は動けない

0:30

PvP 解禁

開始から30秒は撃ち合い不可。この間にチェストを漁る

ROUND 1–2

漁って備える

6分（アンチは縮まない）＋3分。ROUND 1 は銃を持った雑魚敵スカブがうろつく。2ラウンド目からは救援物資が落ちてくる

ROUND 3–4

決戦

3分ずつ。アンチは半径3まで縮む。ラウンドごとにチェストの中身が入れ替わる

WIN

最後の1人

死んでも30秒後にスカブとして何度でも出撃でき、生存者を倒せば復活。最後まで生き残った1人の勝ち

チェスト

中身は「武器だけ」「アイテムだけ」「両方」の3種類。鍵のかかった部屋には★レジェンド、特別な3か所にはマークドチェストがあり、ラウンドが変わっても入れ替わらない一番レアな箱です。

鍵部屋

鉄の扉で閉ざされた部屋が12か所。合う鍵を手に持って扉に近づくと、その試合の間ずっと開きます。鍵はなくなりません。

救援物資

2ラウンド目以降、ニワトリにつながれたチェストがアンチ内のどこかへゆっくり落ちてきます。落下地点の座標は全員に通知。中身はマークド級の武器・防具や大量の回復など。

ボス

Tagilla と Wedge はマップの決まった場所に毎試合出現。倒すと装備と「ボスの核」を落とします。Killa は混沌チケットで呼び出されます。

キル・死亡

  • キルすると体力が最大体力の半分だけすぐ回復（漁夫の利対策）
  • 死ぬと持ち物は死んだ場所の「遺品」チェストに全部入る
  • 死んだ人は30秒後にプレイヤースカブとして戻る（体力20・俊敏II・ナイフ／手斧／ハンドガンのどれか）。生存者を倒すとその場で復活。倒されても30秒後にまたスカブで出撃できる（何度でも）

スカブ

ROUND 1 の間だけ、銃を持った敵「Scav」が24体ほどマップにいます（強めの Scavレイダーも混ざる）。倒すと持っていた銃の弾を必ず落とし、アタッチメントや回復、たまに鍵も手に入ります。ROUND 2 になると撤退して消えます。

02 · 導入手順

遊べるようになるまで

必要なファイルはギガファイル便で配布しています。ギガファイル便には保存期限があるので、早めにダウンロードしてください。

  1. 4つのファイルをダウンロードする

    リンク先で「ダウンロード」ボタンを押すと zip が保存されます。

  2. Forge フォルダを置く場所を決めて解凍する

    「Forge フォルダ」の zip を解凍し、中の minecraft battle フォルダを分かりやすい場所に置きます。

    C:\Minecraft\minecraft battle

    デスクトップや OneDrive の中は避けてください（同期でファイルが壊れることがあります）。

  3. MOD・銃パック・リソースパックを入れる

    • 「MOD」の zip を解凍し、中の .jar ファイルを全部 minecraft battle\mods に入れる
    • 「銃パック」の中の zip は解凍せずに minecraft battle\tacz に入れる（TaCZ は zip のまま読み込みます）
    • 「リソースパック」の BattleRoyale_Items_RP.zip も解凍せずに minecraft battle\resourcepacks に入れる（同じ名前の古いファイルがあれば置き換える）

  4. Forge をインストールする

    • 公式ランチャーで、バニラの 1.20.1 を一度だけ起動して閉じる
    • minecraft battle フォルダの中の forge-1.20.1-47.4.26-installer.jar をダブルクリック
    • 「Install client」を選んで OK。完了の表示が出れば成功です

    jar が開かないときは Java が入っていません。java.com から Java をインストールしてからもう一度試してください。

  5. 起動構成を作る

    公式ランチャーの「起動構成」→「新規作成」で、次のように設定します。

    • バージョン：release 1.20.1-forge-47.4.26
    • ゲームディレクトリ：手順2で置いた minecraft battle フォルダ

  6. メモリの割り当てを増やす（必須）

    MOD と銃が多いので、初期設定の 2GB では落ちたり固まったりします。同じ起動構成の「その他のオプション」→「JVM引数」の先頭にある -Xmx2G を書き換えてください。

    -Xmx8GPC のメモリが 16GB 以上（おすすめ）
    -Xmx6GPC のメモリが 12GB 程度
    -Xmx4GPC のメモリが 8GB（最低ライン・重い）

    PC のメモリの半分を目安に。多すぎると逆に PC 全体が重くなります。CurseForge などを使う場合は、その設定画面の「メモリ割り当て」で同じ値にします。

  7. 起動してリソースパックを有効にする

    起動構成から起動します（初回は数分かかります）。タイトル画面の「設定」→「リソースパック」で BattleRoyale_Items_RP を右側（有効）に移します。オリジナルアイテムの見た目がこれで変わります。

  8. キー設定を整えて参加する

    このあとの「キー設定」の表のとおり、使わないキーを消してから参加してください。参加先：（主催者から案内します）

03 · 操作とシステム

銃の操作と、覚えておくこと

銃は TaCZ、防具は ZeroContact、回復と投げ物は LR Tactical という MOD を使っています。キーは初期設定のものです。

キー操作メモ
左クリック撃つ弾はインベントリに入れておけば OK
右クリック覗く（ADS）スコープ付きはズーム
Rリロードその銃に合う弾がインベントリにあるときだけ
G射撃モード切替セミオート / フルオート / バースト
Zアタッチメント画面スコープ・サイレンサー・マガジンなどを付け替える
Vスコープの倍率切替近接攻撃も初期は V（キー設定を参照）
C伏せ
H点検（銃を眺める）
F役職スキルオフハンドのスキルアイテムで発動。常時発動型は説明が出る
右クリックオリジナルアイテム・回復を使う手に持って使う。回復は長押し
左 / 右クリックグレネードを投げるLR Tactical の投げ物。クリックで投げ方が変わる

インベントリ

  • 使えるのはホットバー9マス＋インベントリ左上5マス。上2段の残りはロック
  • バックパックで1マスずつ解放（小1・中2・大3）
  • 一番下の段は弾薬スロット：拾った弾は弾薬箱に自動でまとまる（1種類1マス・量は無制限・そのままリロードOK）
  • オフハンドは役職のスキルアイテムで固定
  • 飲み終わった空き瓶は自動で消える
  • タグ違いで分かれた食べ物は、持ち替えると1つにまとまる

防具（ZeroContact）

  • ヘルメットは頭、ベスト・プレートキャリアは胴に着るだけ
  • プレートは拾うだけで自動装着（前→後ろ、強い順）
  • 防護クラスが弾の貫通力より高いほど止めやすい
  • 防具が変わるとチャットに今のクラスが出る
  • ズボン・ブーツはバニラの防具

合成（ディスペンサー）

マップにある合成用のディスペンサーに材料を入れると、別のアイテムに変わります。武器・混沌チケット・防具のランクアップ・弾の変換など14種類。やり方とレシピは「合成」へ。

混沌チケット

試合中に生存者だけが使える。使うと8種類のどれかがランダムに起きる：全員発光／全員盲目／持ち物シャッフル／Killa 出現／脱落者の復活／位置入れ替え／隕石「マリコの怒り」／外にいる全員に落雷「天罰の雷」。

回復アイテム

  • AI-2：20回復（3個までスタック）
  • CAR FAK：40回復
  • Surv12：30回復×3回
  • ほかに Propital・金のリンゴ・ステーキ
  • シーカーアームガード中はすごい速さで回復

UAV端末

マップの2か所（105 -62 -67／-72 -42 44）にある端末を右クリックすると、UAVと同じく半径50ブロックの敵が10秒間光る。1か所ごとに60秒の充電あり。

覚えておくと得

  • 不死のトーテムはインベントリにあれば発動
  • ロビーには銃・弾・投げ物を持ち込めない（自動で回収）
  • 爆発でブロックは壊れない
  • ガスマスクを拾うと自動で着け、盲目にならない
  • 額縁に飾られたアイテムは取れる（毎試合元に戻る）
  • 手配書を使うとキル数トップが3分間光る

04 · 合成

ディスペンサーで合成する

マップにある合成用のディスペンサーに材料を入れると、0.5秒ほどで完成品に変わります。作業台は使いません。

合成用のディスペンサーを探す

マップに6か所あります。普通のディスペンサーと見た目は同じなので、座標を覚えておくと便利です。

-18 -51 129142 -60 31-123 -13 -138-41 -60 -21130 -44 -5960 -53 -16

右クリックで開いて材料を入れる

9マスのどこに入れても大丈夫です。順番も関係ありません。材料が多すぎても、余った分はそのまま残ります。

変わったら取り出す

条件がそろうと0.5秒以内に完成品に変わります。何回分も入れた場合は、0.5秒ごとに1回ずつ合成されます。

防具のランクアップの順番

防具かヘルメットと予備のプレートを1枚（種類は自由）入れると、下の順番で1段階上になります。着けているプレートは材料にならないので、別のプレートを入れてください。

ヘルメット　帽子 → 6B47 → Hound Wolf → UNTAR → TBH → AirFrame → Bastion（黒）→ British23 ／ 帽子（水色）→ 6B47（Arctic）→ Phonetalker → C2R → AirFrame ／ Bastion（緑・迷彩）→ British23

プレートキャリア　JPC v1 → Hexgrid → JPC v2 → AVS → Defender-2 → SS Lv119 ／ Thor → FCPC → Hound Wolf → C2R Lite → IOTV

ベスト　6B2 → UNTAR → IBA OTV → 6B23-1 → 6B43 ／ 6B23-2 → 6B43

05 · キー設定

邪魔なキーを消しておく

MOD が多く、初期設定のままだとリロードの R で別の画面が開くなど、同じキーがぶつかっています。「設定」→「操作設定」→「キー割り当て」で、下の項目を選んで Esc を押すと「なし」にできます。赤字のキーはぶつかっている印です。

どうするカテゴリ（MOD）項目初期キー理由

F（オフハンドと持ち替え）は役職スキルに使うので消さないでください。TaCZ のキー（R・G・Z・V・C・H）もそのまま使います。

06 · 役職

10種類の役職

試合開始時に全員へランダムで割り当てられます（同じ試合で重複なし）。オフハンドに入るスキルアイテムを F で使います。

07 · アイテム

オリジナルアイテム

右クリックで使うものが中心です。チェストのレア度は星の数が多いほど出にくいアイテムです。

見つかりませんでした。

08 · ボス・スカブ

ボスとスカブ

体力100、攻撃力上昇II。ボスの弾は当たるたびに6ダメージが上乗せされます（最大30）。倒すと装備と「ボスの核」を必ず落とします。ボスの装備はチェストからは出ません。

スカブ（ROUND 1 だけの敵）

銃を持って向かってくる敵です。倒すと弾や装備が手に入るので、序盤の装備集めに。

09 · ゲームモード

チームデスマッチ

赤と青の2チームに分かれて10分間。相手を倒した数が多いチームの勝ちです。役職・アンチ・インベントリのロックはありません。

セットを選ぶ

始まるとチャットに3つのセットが出ます。［セット1］〜［セット3］をクリックして選びます（最初の20秒が選択時間）。選ばなかった人はランダムです。

毎試合ちがうセット

アサルト・スナイパー・近接戦・サポート・マークスマンの5種類から3つが選ばれ、銃・防具・アイテムも毎回ランダムに変わります。どのセットにも全部の弾が無限に使える弾薬箱と、ステーキ・金のニンジンが入っています。

倒されたら

3秒後に自分のチームの陣地で、選んだセットを持って復活します（3秒間無敵）。死んだときにセットを選び直すと、次の出撃から変わります。

10 · 射撃訓練場

射撃訓練場と1vs1

ロビーの 1076 -53 1161〜1165 に乗ると訓練場へ、訓練場の 968〜972 -60 1121 に乗るとロビーへ戻ります。訓練場の箱の中身は何度でも取れます。

取り放題の箱

  • 銃：バトロワに出る全52丁＋全部の弾が無限に使える弾薬箱
  • 防具：バトロワに出る防具54種
  • オリジナルアイテム54種
  • 石：投げて当てた相手を2秒間スタン

ボタン

  • 980 -59 1154：1vs1に参加
  • 980 -59 1156：持ち物リセット（全部消える）
  • 980 -60 1152：合成を試せるディスペンサー
  • ボタンは、見て押した本人に効きます

持ち込みのルール

  • オリジナルアイテムは1vs1会場（x 970より西）に持ち込めない
  • ロビーには銃・弾・投げ物を持ち込めない（自動で回収）

1vs1

ボタンを押した人が2人以上で5秒後に開始。1人目と2人目は向かい合わせに出ます。左手の不死のトーテムが発動するか、会場の外に出たら負け。戦っている間は自然回復なし・名前は非表示。制限時間3分。

エイム練習（30体撃ち）

983 -59 1135（イージー2秒）／1136（ノーマル1.5秒）／1137（ハード1秒）のボタンで開始。ボットが1体ずつ30回出て、最後に何体倒せたかが出ます。練習中はリロード不要。

連続撃破モード

983 -59 1126 のボタンで開始。ハードと同じ1秒で、1体でも逃すと終わり。連続で倒した数と自己ベストが表示されます。
